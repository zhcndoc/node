# 安全管理员入职/离职

## 入职

* 确认新的管理员同意对项目中的所有私密信息保密
  ，且不会向其雇主使用/披露这些信息。
* 将他们添加到 GitHub nodejs-private 组织中的 security-stewards 团队。
* 将他们添加到 [public website team](https://github.com/orgs/nodejs/teams/website)。
* 确保他们已在 H1 中启用 2FA。
* 使用此
  [页面](https://hackerone.com/nodejs/team_members) 将他们添加到 H1 的标准团队中。
* 将他们添加为
  [nodejs-sec](https://groups.google.com/g/nodejs-sec/members) 邮件列表的管理员。

## 离职

* 从 GitHub nodejs-private 组织中的 security-stewards 团队中移除他们。
* 从 public website team 中移除他们
* 除非他们因其他原因仍有访问权限，否则使用此
  [页面](https://hackerone.com/nodejs/team_members) 将他们从 H1 的标准团队中移除。
* 将他们在
  [nodejs-sec](https://groups.google.com/g/nodejs-sec/members) 邮件列表中的账号降级为普通成员。
