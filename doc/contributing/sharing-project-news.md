# 分享项目新闻

该项目旨在让那些发布涵盖 Node.js 的新闻通讯的人更容易分享项目新闻。

该项目的方法如下：

* 项目将在 `nodejs/node` 仓库中创建一个 “YYYY 年有什么新内容” 的讨论条目，用于与 Node.js 核心相关的新闻。
* 各团队/小组可以在其一个或多个仓库中创建一个 “YYYY 年有什么新内容” 的 issue 或讨论条目。示例请参见
  [Node-API 和 node-addon-api 世界有什么新动态？- 2023 版](https://github.com/nodejs/abi-stable-node/issues/446)。
* 贡献者会在全年期间定期将新闻作为额外评论添加到这些 issue 中。
* 在每年年底，该 issue 会被关闭，如适当，则会创建一个新的 issue。
* 下方部分会维护这些文档的列表，以便快速查找。
* next-10 团队会根据需要主动联系各团队/小组，以确保团队知晓这种分享新闻的选项。
* next-10 团队会根据需要主动联系新闻通讯发布者，让他们了解这种方法，以及他们如何找到这些更新。

我们信任/期望贡献者发布与项目相关的新闻，而不是宣传某个特定公司或商业利益的新闻。
