## 2026-05-07, Version 26.1.0 (Current), @aduh95

### Notable changes

#### Experimental `node:ffi` module

Node.js now includes an experimental `node:ffi` module for loading dynamic
libraries and calling native symbols from JavaScript.

This API is gated by `--experimental-ffi`, and requires `--allow-ffi`
when the Permission Model is enabled.

This API is fundamentally unsafe. Invalid pointers, incorrect signatures,
or accessing memory after it has been freed can cause process crashes or
memory corruption.

Contributed by Paolo Insogna in [#62072](https://github.com/nodejs/node/pull/62072).

## 2026-05-05，版本 26.0.0（当前），@RafaelGSS

我们很高兴宣布 Node.js 26 正式发布！亮点包括默认启用 Temporal API、
将 V8 JavaScript 引擎更新到 14.6、将 Undici 更新到 8.0，以及若干重要的弃用和移除，
这些都是我们持续推动平台现代化的一部分。

提醒一下，Node.js 26 将于 10 月进入长期支持（LTS），但在此之前的接下来六个月里，它将作为“当前”版本发布。
我们鼓励你探索此最新版本提供的新特性和优势，并评估它们对你的应用可能产生的影响。

### 重要变更

#### Temporal API

Node.js 26 现已默认启用 Temporal API。Temporal 是 JavaScript 的现代日期/时间 API，
为旧版 `Date` 对象提供了一个更健壮、功能更丰富的替代方案。

由 Richard Lau 在 [#61806](https://github.com/nodejs/node/pull/61806) 贡献。

#### V8 14.6

V8 引擎已更新到 14.6.202.33 版本，这是 Chromium 146 的一部分。

此版本还包括：

* Upsert (<https://github.com/tc39/proposal-upsert>): `[Weak]Map.prototype.getOrInsert()`, `[Weak]Map.prototype.getOrInsertComputed()`
* 迭代器顺序化 (<https://github.com/tc39/proposal-iterator-sequencing>): `Iterator.concat()`

由 Michaël Zasso 在 [#61898](https://github.com/nodejs/node/pull/61898) 贡献。

#### Undici 8

Undici 已更新到 8.0.2 版本，为 Node.js 的 HTTP 客户端实现带来了新特性和改进。

* \[[`dff46c07c3`](https://github.com/nodejs/node/commit/dff46c07c3)] - **(SEMVER-MAJOR)** **crypto**: 将 DEP0182 移至生命周期结束（Tobias Nießen）[#61084](https://github.com/nodejs/node/pull/61084)
