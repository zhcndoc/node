* 主要 API 变更
  * 移除 'file' 模块
  * require('posix') -----------------> require('fs')
  * fs.cat ---------------------------> fs.readFile
  * file.write -----------------------> fs.writeFile
  * TCP 'receive' 事件 --------------> 'data'
  * TCP 'eof' 事件 ------------------> 'end'
  * TCP send() -----------------------> write()

  * HTTP 'complete' 事件 ------------> 'end'
  * http.Client.prototype.close()（原为 finish()）不再
    接受参数。请手动添加 'response' 监听器。
  * 允许 fs.open 的 flag 参数使用字符串
    （"r"、"r+"、"w"、"w+"、"a"、"a+"）

* 为 sys.puts()、print() 等添加多参数支持
  （<tj@vision-media.ca>）
